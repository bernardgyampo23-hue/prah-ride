# Prah Ride 🇬🇭
Ghana's smart ride-hailing platform operating exclusively in Sekondi-Takoradi, Western Region, Ghana.

### 🚕 About Prah Ride
Prah Ride connects riders and drivers in Sekondi-Takoradi with fast, affordable, safe rides. Built in Takoradi, for Takoradi.

### ✨ Features
- 2-click ride request in Sekondi-Takoradi
- Real-time driver tracking
- Installable App (PWA) - works on iOS & Android without Play Store
- 0% commission for drivers - first 3 months
- Cash & Mobile Money

### 📱 Live App
**https://prah-ride.vercel.app**

How to Install:
1. Open link on your phone
2. Android: Tap "Install Prah Ride"
3. iPhone: Tap Share → Add to Home Screen

### 🛠️ Tech Stack
Next.js 14, Tailwind CSS, PWA, Vercel

### 📍 Coverage
Sekondi-Takoradi only - We are focused on serving Western Region better than anyone else.
